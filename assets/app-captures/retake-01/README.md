# צילומי השלמה (retake-01)

> **כל הנתונים בצילומים הם נתוני הדגמה פיקטיביים.** אלה אותם נתוני דמו של הסט הראשי: "מלצרות – קפה גליל" ו"שמירה – מתנ"ס הדר" (באנגלית: "Waiter – Galil Café" ו-"Security – Hadar Center"). אין בהם פרטים אישיים.

| | |
|---|---|
| גרסת האפליקציה | 1.8.1 (versionCode 38), build debug מקומי |
| רזולוציה | 1080×2400, PNG מקורי, בלי חיתוך, מתיחה, מסגרת או ריטוש |
| תאריך ההדגמה | יום רביעי, 28.10.2026 (יום רגיל. בדקתי בצילומים שאין באנר בחירות או תעריף מיוחד) |
| היום הנבחר ביומן | 2.11.2026, שבו יש משמרת מתוכננת אחת |
| מצב תצוגה | כהה, גודל גופן ברירת מחדל, שורת סטטוס במצב הדגמה (בלי התראות) |

הערות:
- ביומן מופיע המקרא הכללי "חג (150% / 200%)". הוא חלק קבוע מהמסך, ולא הודעה על יום מסוים.
- "4/4 תזכורות מתוזמנות" זה מה שהאפליקציה מציגה עבור משמרת מתוכננת עם תזכורות.
- כל המסכים שהתבקשו צולמו. לא צולמו מסכי Pro חדשים, כפי שהתבקש.
- לפני הצילום נשמר גיבוי של הנתונים המקוריים, ובסוף הם הוחזרו ונבדקו בהשוואה בית-אחר-בית. התאריך האוטומטי, מצב הלילה ושורת הסטטוס הוחזרו, ו-Metro והאמולטור כובו. קוד האתר והאפליקציה לא השתנו.
